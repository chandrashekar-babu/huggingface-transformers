# HuggingFace Transformers: API, Models and Fine-Tuning Techniques

This hands-on course provides a comprehensive exploration of the HuggingFace Transformers ecosystem, covering model architectures, APIs, and practical fine-tuning techniques. Participants will learn to leverage pre-trained transformer models for various NLP and multimodal tasks, understand the underlying architectures, and gain practical experience fine-tuning models on custom datasets. The course emphasizes experimentation on local machines, making it accessible for lab environments without requiring extensive cloud resources.

This repository hosts the code samples, notebooks and presentations for this training course.
